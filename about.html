About us

Uniting Heroes, Saving Lives
One Umbrella, Infinite Hope.

This project aims to build a centralized platform for rescue agencies to register their information and display their locations during disasters. The platform will include a database for agency information, a map interface for visualizing locations, and filters for refining search results. It will also feature communication tools for agencies to collaborate and request assistance. Security measures will be implemented to protect sensitive information.
